# Pagination is typed from the server's `x-paginator` stamp, and an unreadable paginator warns

Page keys can be renamed and a `MultiPaginator` offers several strategies at once, so member names alone can't say how a collection paginates. The stamp decides the strategy and keys, canonical names are the fallback, and anything unrecognised generates as unpaginated with a warning rather than an error, under the same rules as the PHP codegen. The `page` argument is typed per collection, a menu as a union discriminated by `kind` with the default arm untagged, and `$page` is typed by the strategy that will answer, inferred from `page` through a `const` type parameter.
