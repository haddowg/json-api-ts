# Angular bindings use TanStack Query over the normalised cache

Supersedes [ADR 0005](0005-angular-bindings-are-signals-over-an-httpclient-transport-with-no-shared-cache.md), which rejected TanStack for Angular only because its Angular adapter was experimental; `@tanstack/angular-query` is now stable, and Angular apps need the shared cache, optimistic writes and devtools that the signal bindings lack. So `@haddowg/json-api-angular/query` hands the existing `json-api-query` option factories and its `type:id` normalised cache to TanStack's own `injectQuery`/`injectMutation`, adding only DI providers, typing and an error pipe rather than wrapping TanStack, and `@haddowg/json-api-query` is an optional peer so one copy serves the app and the bindings. The signal path (`jsonApiResource`/`jsonApiMutation` over `resource()`) stays in the root entry as the light option for apps that want no cache.
