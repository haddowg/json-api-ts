# Declared document meta types a collection's `$meta` and a resource's `$document.meta`

A server can declare the members of an operation's top-level `meta`, and the client types them where a result already carries that `meta`: `$meta` on a collection, `$document.meta` on a single resource, and the value itself for a meta-only delete or action. A resource's own `$meta` stays the resource object's meta, since retyping it with the document's would misreport what the runtime returns. The members ride the descriptor as format hints, the way pivot fields and identifier meta do, so a hand-written descriptor can declare them and no new type argument has to thread through the client, query and Angular bindings; a member typed as an object or list reads as an open record or array as an attribute's hint does.
