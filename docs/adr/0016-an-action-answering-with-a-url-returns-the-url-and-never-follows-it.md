# An action answering with a URL returns the URL and never follows it

The client asks for JSON:API, so an action that hands out a URL answers with a `200` location document rather than a `303`, and the client returns `{ url, type, expiresAt? }` rather than fetching it: the target is usually object storage on another origin where the client's auth headers don't belong, and a browser downloads a file better by navigation than through a `Blob`. The MCP tools do the same, and the descriptor marks the action (`location`, and `output: 'location'` when that is all it answers with) so consumers don't infer the shape from schemas.
